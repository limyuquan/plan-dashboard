ELI5·plan-dashboard v1·Phase 2: split-tree pane layout

New panes get a wall, not a whole new floor

Think of the dashboard screen as a house and every pane as a room. The old house was built in rigid floors, so changing one room moved walls everywhere. The new house lets you put a wall through one room, knock one down, and walk to the room that really is next door.

Built from web/layout/model.ts and its tests in web/layout/model.test.ts. The old design is described from the phase brief; its code is not in this repository's history.
